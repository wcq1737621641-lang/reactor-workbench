# 演示与录屏脚本

## 目前可展示的本地功能

运行 `npm start`，打开浏览器。先讲清右上角环境状态。没有 HYSYS 的本地电脑只能规划或独立校核。

1. 点击甲烷蒸汽重整，分析。展示 Equilibrium 选型原因、两条反应、710/600 °C 两个独立工况、自定流量与平衡假设。不展示未经 HYSYS 计算的产品数值。
2. 点击甲苯歧化。先删除异构体比例后分析，展示澄清问题。补回异构体比例，分析并接受假设，执行计量校核。说明 50% 转化率和三种异构体比例分别决定什么。
3. 点击其他反应/JSON，展示乙烯加氢，校核进出料证明计算来自计量矩阵，而不是两套固定产品表。可改变转化率 0.8 为 0.6 重新运行。

`docs/evidence/local-demo.webm`（如已生成）只记录本地功能，**不是考核要求的 HYSYS 录屏**。界面截图同样不能作为实际求解证据。

## HYSYS 适配完成后必须另行录制

推荐 OBS 录制远程工作站全屏，1080p，展示网页与 HYSYS。录制前完成适配器验收并配置真实 LLM 服务。

1. 从原始自然语言开始，现场生成方案，展示选型与假设。
2. 执行重整两温度工况，切到 HYSYS 展示新建反应器、反应集、流股和收敛状态，再回到界面对比组成。
3. 甲苯歧化主动澄清比例，真实运行，展示计量、转化率、汽液出口及总衡算。
4. 新输入一个额外相关反应（如乙烯加氢），证明动态创建与求解能力。
5. 展示生成的 `.hsc`、`plan.json`、`result.json` 和日志，结束录制。

答辩时应能解释：为什么蒸汽重整优先平衡模型；为什么已知转化率采用 Conversion；为什么总转化率不能唯一确定二甲苯选择性；为什么气相/液相不是没有动力学时的唯一选型依据；为什么未知候选产物的 Gibbs 模型仍依赖组分集合。
