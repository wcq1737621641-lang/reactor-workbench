## 关键决定

1. 数据与执行分离。AI 只出 JSON 方案，不执行生成的代码；确定性程序检查可执行性。
2. 三种计算来源显式区分。规划不是结果；计量校核不包含物性/热量/分相；只有通过 COM 读取且衡算通过的结果可标注 HYSYS。
3. 采用本地 Web + CLI，方便现场演示，又能在 HYSYS 工作站运行，无需公网部署。
4. 反应创建接口以实机类型库为准。没有给猜测的 COM 成员加虚假兼容承诺；未实现适配器时禁用实算按钮。
5. 密码、RDP 内容、远程桌面截屏和其他应用画面不纳入代码包；会话导出脱敏凭证与远程地址。
